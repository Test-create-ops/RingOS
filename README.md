# RingOS

# **About It**

RingOS is a Custom OS without any OS Under it, it means that the OS has its own APIs, its Own SDK (RingSDK..soon), Everything is Property of RingOS

# **How it was created (backstory)**

RingOS, before having UI, it had several modifications, like using the Comfortaa Font instead of the new font of RingOS, then it eventually turned from terminal -> UI.

# **Why did RingOS pop out of my brain?**

RingOS is the **Successor** Of KairoOS (repo: KairoOS-Beta), Cuz it just dint have enough Downloads/Interest.
